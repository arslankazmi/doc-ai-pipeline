Capabilities

What It Does

Three model backends, one unified API, and a full human-in-the-loop correction cycle.

🔍

Multi-Model Extraction

Qwen2-VL-2B, Donut, and PaddleOCR+TrOCR run in parallel. Results are compared to find the most confident extraction across all three backends.

🎯

Confidence Routing

Platt-calibrated probability scores route easy cases (≥ 0.85) straight through to the response. Hard cases are queued for human review automatically.

🔄

HITL Feedback Loop

Human corrections in the review app automatically flow back through export_feedback.py into the next training run — the model gets better with every correction.

📊

Benchmark Suite

Built-in benchmark.py compares all three models on accuracy, latency, and percentage of hard-routed cases across your evaluation dataset.

🐳

Docker Compose

Two isolated services (pipeline :8000, HITL :8001) sharing a single SQLite database, brought up with one command: docker compose up --build

🇰🇷

Korean HTR

Native Korean handwriting recognition across all three backends. Tested on real Korean registration and intake forms with mixed print and cursive script.

Reference

API Endpoints

Both services expose a REST API. The pipeline service runs on port 8000; HITL on port 8001.

Endpoint Method Description
/health GET Service health check — returns model load status
/extract POST Extract fields from a base64-encoded image; returns JSON + confidence
/demo GET Browser upload demo UI — drag-and-drop extraction
/demo/compare/{id} GET Side-by-side 3-model comparison view for a given case
/queue HITL GET Pending case queue — list all cases awaiting human review
/case/{id} HITL GET Load a specific case for review with original image and extracted fields
Get Started

Quick Start

Run both services locally with uv, or spin up the full stack with Docker Compose.

bash
# Clone and install dependencies with uv git clone https://github.com/arslankazmi/doc-ai-pipeline cd doc-ai-pipeline uv sync # Start the inference pipeline (port 8000) PYTHONPATH=src uv run uvicorn pipeline.api:app --port 8000 --reload & # Start the HITL review app (port 8001) PYTHONPATH=src uv run uvicorn hitl.app:app --port 8001 --reload & # Open the demo UI open http://localhost:8000/demo
bash — Docker Compose
# Or run the full stack with Docker (no Python setup needed) docker compose up --build # Pipeline API: http://localhost:8000 # HITL App: http://localhost:8001 # Demo UI: http://localhost:8000/demo
bash — Calibrate & Benchmark
# Fit the Platt confidence calibrator on your eval set uv run python scripts/calibrate.py # Benchmark all 3 models: accuracy, latency, hard-route % uv run python scripts/benchmark.py # Export corrected cases as training data + retrain uv run python scripts/export_feedback.py uv run python scripts/retrain.py
